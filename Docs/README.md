## 5. 写作口径

- 已完成并验证：使用“已实现”“已完成”“已验证”。
- 正在开发：使用“正在接入”“开发中”。
- 未来计划：使用“计划”“后续扩展”“待实现”。
- 当前不能把迭代04之后的动作战斗、状态同步、战斗事件同步写成已完成成果。
